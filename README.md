**Goal of the project**: To restore functionality to the **Waze** app, version **3.9.6**, on a jailbroken **iOS 6** device (ex. iPhone 4/iPhone 4S/iPhone 5).

## Why?

The old Waze app was still working properly in 2025 (directions, voice guidance, etc.). Overnight,
the app stopped working. This is a server-side issue that the Waze app cannot resolve. It seems that Waze have changed the way the API works. We therefore need to analyze the app’s requests
to propose an appropriate fix.
